# Registrar rules

Rules from Yale SOM's Registrar's Office that affect how SOMtimes counts or
warns about courses. **The app doesn't use these yet**: today every non-SOM
course counts 0 units (`docs/specs/cross-registration.md`). Check this file
before changing units, requirements or warnings for courses from other schools.

## Yale Law School (YLS) — from the SOM Registrar, Nov 2026

- **One Law course per semester.** SOM students may take only one YLS course
  each semester. Cross-listed MGT/LAW courses don't count toward that limit.
- **Units convert 1 to 1.** 1 YLS unit = 1 SOM unit.
- **Ranges count as the lower number.** A YLS course listed as "1 or 2 units",
  "2 or 3 units", etc. counts as the lower number, unless the student can prove
  they did the extra work for the higher one.
